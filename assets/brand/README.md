# Brand assets

The ReyDesk mark is the amber geometric open-C/screen mark. Canonical vector: [reydesk-mark.svg](../../docs/assets/reydesk-mark.svg). A transparent PNG preview and reproducible platform export script live alongside it. Native Windows path geometry and Android VectorDrawable use the same two paths; launcher/taskbar/tile assets are exported at platform sizes.

The compact header pairs the mark with the ReyDesk wordmark using platform typography. The historical ReyDen S horizontal PNGs remain preserved but are superseded for the approved-reference interface.

Color/type and reference mapping: [design-system.md](../../docs/design-system.md). No additional icon package is required; use consistent native outlined control/device icons with accessible names.
